# ALRYA — Security and Privacy

This public repository contains documentation only.

## Not published

- Production source code
- Credentials and environment secrets
- Customer data
- Internal prompts
- Webhook secrets and provider tokens
- Proprietary Rate Engine implementation
- Detailed infrastructure secrets

## Multi-tenant isolation

Organization and company scope are part of the authorization model. Tenant-sensitive operations preserve the correct organization/company context.

## Authentication and authorization

The production architecture uses authenticated sessions and explicit role/permission resolution. This repository documents the model without exposing implementation-sensitive details.

## Customer data

No real customer, reservation, lead, conversation or revenue records should be published here.

Any future public code example must be synthetic and independent from the production implementation.
